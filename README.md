# 🧪 Teste técnico — Target Sistemas

Resolução das questões de um teste técnico, em Python e C++.

| Arquivo | Questão |
|---|---|
| `questão-1.py` | Soma acumulada de 1 até um índice com laço `while` |
| `questão2.py` | Sequência de Fibonacci com a quantidade de termos informada |
| `questão 2 fibonacci.cpp` | Fibonacci em C++, conferindo se um número informado está na sequência |
| `questão 5.cpp` | Inverter os caracteres de uma palavra sem usar função pronta |

## Como rodar
```bash
python questão2.py
g++ "questão 5.cpp" -o q5 && ./q5
```
